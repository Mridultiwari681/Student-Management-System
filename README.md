# 🎓 Student Management System in Java

## 📌 Project Overview
The Student Management System is a console-based Java application designed to manage student records efficiently.

It allows users to add, view, search, update, and delete student information through a simple menu-driven interface.

## 🚀 Features
- ➕ Add a new student
- 📋 View all student records
- 🔍 Search students by roll number
- ✏️ Update student information
- 🗑️ Delete student records
- 🚫 Prevent duplicate roll numbers
- 🔄 Menu-driven interface

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Git and GitHub

## 📚 Concepts Covered
- Classes and Objects
- Constructors
- Methods
- Encapsulation basics
- ArrayList
- Loops and Conditional Statements
- CRUD Operations

## ▶️ How to Run

1. Install Java JDK on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the program:

   javac StudentManagementSystem.java

5. Run the program:

   java StudentManagementSystem
